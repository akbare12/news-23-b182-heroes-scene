# THE WORLD TODAY — Monday 23 November 2026

One image summing up 23 November's world news: the AI rout that hit Asia
(Kospi −3.3%), Guterres calling to regulate AI before it's too late in
Bridgetown, and the US lead over China at a record low in the Asia Power
Index — plus 28 more stories, a world map with 13 places, and a DATE CHECK
box naming what did *not* happen on 23 November.

## How it is built

- `draw.py` (Pillow) renders `entry.png` (1024×1024, ≤1 MiB).
- `main.py` (Python standard library only) verifies `entry.png` and writes a
  byte-identical copy to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it with
  `python3 -P -s main.py`.

## Facts

Every number comes from the wires for 23 November 2026. Items marked CLAIM
are one side's claim, not independently verified. Stories dated 22 November
or earlier appear only in the red DATE CHECK box, never as news.
